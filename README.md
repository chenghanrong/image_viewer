# 🖼️ 图片像素查看器 (Image Pixel Viewer)
---
一个基于 Python `tkinter` 开发的轻量级图像查看工具，支持实时显示鼠标所在位置的图像坐标与像素值（RGB或灰度）。有些臃肿后续考虑使用c++开发一个版本......
---
## ✨ 功能特性

- 📂 **多样打开方式**：支持点击“打开图片”按钮，或直接**拖拽**图片文件至软件窗口内。
- 🖱️ **像素实时追踪**：鼠标在图片上任意移动，底部状态栏实时显示对应的 **原图坐标 (X, Y)** 及该点的 **像素值**（自动识别灰度或 RGB 格式）。
- 📐 **自适应与居中**：图片自动缩放以适应窗口大小，且始终保持居中显示；调整窗口大小时图片实时重绘居中。
- 🖼️ **文件夹快速浏览**：打开一张图片后，自动扫描同目录下的所有图片。你可以使用键盘的 **`←` (左) / `→` (右)** 方向键，或直接点击界面上的 **“上一张” / “下一张”** 按钮进行循环切换。


## 🖥️ 运行环境与依赖

- 操作系统：Windows / macOS / Linux
- Python 版本：3.6 或更高

### 第三方库依赖

- `Pillow` (用于图像处理)
- `tkinterdnd2` (用于支持文件拖拽功能，若不需要拖拽功能可忽略)
